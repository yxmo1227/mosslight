# v0.7 local trial checklist

This is release preparation, not authorization to publish. Build approval does not authorize creating a GitHub repository, uploading releases or changing production. Use `--publish never` for local packaging.

## Scope

Warm original Canvas 2D art; footprint/root contact; direct pointer palette placement with cancellation; per-entity 40–200% size; editable deadwood trunk and up to three branches; shared drawing/hit/support geometry; bounded cosmetic wetness/weathering; exact-byte pre-v0.7 compatibility backups. Keep existing pond, glass, terrain and widget-care flows.

## Required evidence

- Strict type checking, all core/desktop/renderer tests and actual main/storage boundary tests.
- Real captured-pointer catalog drag, no click-auto-add, release/cancel/Escape, selected dragging and all-family scaling.
- Branch count/length/direction, stone/stump/wood stacks, attached moss/mushrooms, finite support spans and actual opaque-footer contact on flat/sloped terrain.
- Save/restart with shape and support unchanged; older saves untouched until optional features are used; preservation failures reject overwrite.
- Isolated Electron smoke checks and screenshots; never use normal user data for fixtures.
- Final Windows ZIP extraction, version and license contents, source manifest hashes, clean-source dependency installation/build and isolated smoke reproduction.
- Independent review of final candidate. Any relevant source or runtime change invalidates earlier artifact approval.

## Verification record

The delivery includes `Mosslight-0.7.0-VERIFICATION.md` beside the source/Windows ZIPs. It records actual test counts, exact hashes, independent results and exclusions after they have completed. This source document intentionally contains no premature PASS claim.

## Limits

Original illustration, not full material/structural physics. Geometry edits are bounded; rooted plants and rigid objects are not stretched around extreme gaps. Weathering never removes supports. Maximum 24 plants, 20 objects and support depth six remain. No unrestricted tree generator, autonomous tree growth, network AI or external reference assets.

Windows packages are unsigned. Do not bypass SmartScreen/antivirus. Native OS click-through, focus, DPI/multiple monitors, physical power events, file-picker UX, failures and long-duration performance need separate device testing. macOS builds/notarization are not verified. NSIS embedded-plugin licensing remains unresolved; no Setup distribution. GitHub publication requires explicit release approval.
