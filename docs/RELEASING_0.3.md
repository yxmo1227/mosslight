# Mosslight 0.3.0 本地验证与发布门禁

本轮准备 Windows x64 完整 ZIP 与源码 ZIP，不上传或公开发布。本文是实现契约与验收清单，**不是所有检查已通过的报告**。具体检查数量、日期、环境、候选摘要和最终归档结论见随包验证记录；v0.1 / v0.2 历史数量不适用于本轮。

## v0.3 实现范围

- Three.js 0.186.0 / WebGL2 三维网格、材质与灯光场景；三维渲染结果合成到透明画布，工具粒子可使用二维叠加，图标可使用二维原画。没有运行时下载模型、纹理、字体或 HDR 图片。
- 六种材质使用不同颗粒外形，地形呈现服从容器内壁。权威存档仍是 48 列、每列最多 40 个材料单元，不是三维颗粒 / 流体 / 洞穴刚体引擎。
- 更大单次有界倒料、局部向低处分散；圆形铲土范围和小 / 中 / 大尺寸。不改变任意顺序堆叠、表层移除、远处地形保持的契约。
- 七种容器；旧 glass-box 显示为琢形玻璃盏，新增猫耳瓶。捏形参数限制为 lower / middle / upper 各 0.55–1.25，facets 为 6 / 8 / 10 / 12；不是任意顶点编辑。
- 桌面左键透明阳光 / 喷壶图形，无常驻文字和底框，保留无障碍名称；右键管理和工具退出语义保持。
- schema 2 的可选 glassForm 与 cat 枚举扩展；旧普通 v0.2 数据可读，反向不保证。首次写入扩展前，已有兼容主文件 / 备份原文保存为 before-v0.3 独立副本；已有有效恢复副本不替换，保护失败阻止覆盖。
- 保留严格 v1 校验和 / 迁移原件保护、导入限制、离线 1×、运行默认 24×、暂停、养护边界和本地优先。重置流程不在本轮重设计范围。
