# Mosslight 0.2.0 本地验证与发布门禁

截至 2026-09-18，v0.2 是已有冻结源码功能证据的本地试用版，不是完整原生桌面验收或公开发布批准。只准备 Windows 完整 ZIP 和源码 ZIP，不上传 / 发布。[v0.1 历史发布记录](RELEASING.md) 保持不变，其数量、摘要与审阅结论不覆盖本轮。

## 已完成的冻结源码验证

- `npm run check`：类型检查、245 项测试与构建通过，包括 227 项 TypeScript 测试与 18 项主进程 / 存档边界测试。实现方与独立 QA 分别执行通过。
- 界面流程：26 项通过，66 次动作、12 次交互结束保存，最大待处理动作数 1，页面错误 0。
- 独立真实 Electron 功能检查：9 项通过、页面错误 0，覆盖旧档原件保护、实际鼠标按住 / 取消 / 隐藏、有限喷雾锥命中与持久化。运行使用与冻结源码逐字一致的新鲜构建，检查末尾无构建漂移。
- 源码阶段已进行独立安全复核；最终文档 / 源码变更与实际交付归档需要最后证据绑定，不能由源码阶段结论推断所有平台、许可证义务或产物已获准发行。

上述功能与回归覆盖包括 schema 2 的严格输入边界、旧档迁移 / 保留失败保护、非平地形与材质顺序、菜单分工和有界连续工具。自动逻辑、界面事件与真实 Electron 功能检查的通过，不表示真实断电、电源事件、OS 点击穿透或所有原生文件对话框都已验收。

## 实现与保护契约

- schema 2 地形是 48 列、每列最多 40 个有效材质颗粒；先后倾倒顺序保留，小铲挖出局部坡谷，植物 / 小物在地形表面落点。不支持体积洞穴或悬空石顶。
- v1 原始 checksum 与严格旧结构先于迁移；存档封装 version 2 与 state schemaVersion 2 一致。
- 有效本地 v1 主文件与备份在覆盖前保留逐字一致原件；读取 / 原件保留失败阻止覆盖，保留读取 / 导出恢复路径。损坏主文件不得覆盖有效备份。
- 导入只处理受大小 / schema / checksum 限制的数据，不执行内容；保留当前电脑偏好，不补算外部文件离线时间。测试只用临时样例，不修改真实瓶子。
- 六容器 / 六原创材质，敞口容器无盖，玻璃箱透明盖；左键快捷养护，右键管理，拿工具时右键先退出工具。
- 连续工具有松开 / 取消 / 丢失捕获 / 失焦 / 隐藏 / 放下清理和交互结束保存。喷洒直接或有限下落锥命中一个可见目标，剂量有界；阳光不永久改写环境光。
- 保持在线默认 24×、相对倍速、离线 1×、暂停与异常时钟规则。完整操作与升级 / 回退边界见 [用户指南](USER_GUIDE.md)。

## 分发前的最终归档门禁

下面是独立于上述冻结源码功能结果的交付要求。结果记录在包外的本轮交付证据 / 校验和清单中，绑定最终候选版本、环境、日期、真实命令、数量与发现；**本源码文档不预先声明后续归档验证通过，也不写入源码 ZIP 自身摘要**。定稿后不要仅为填包自身摘要反复改变源码归档。

- [ ] 最终文档 / 源码冻结后完成独立 QA 和安全 / 许可证最后复核；失败不得隐藏或降低等级。相关变更使旧批准失效。
- [ ] 最终源码 ZIP 在全新目录完整解压，官方 registry `npm ci`、`npm run check`、Electron 运行时准备与真实启动；记录实际结果，不继承工作目录或 v0.1 结论。
- [ ] 源码清单逐项大小 / SHA-256 与实际文件一致；不含依赖目录、编译物、发行目录、真实存档、凭据、个人路径、内部简报或原始证据。
- [ ] 最终 Windows ZIP 完整解压运行，不只验证构建目录 EXE；功能 / 候选冒烟与页面错误记录绑定真实包，不把尚未执行的最终脚本数量当成已通过。
- [ ] 最终 app.asar / ZIP 内容、文件清单与摘要核对；实际产物保留 Electron / 内含组件许可原文并与上游比对，无意外 NSIS / elevate 组件。
- [ ] 实际 EXE 的 ProductName、版本、原创图标、Authenticode 状态在产物上核验，不由配置推断。
- [ ] 两包最终文件名、字节大小、SHA-256、候选摘要与对应审阅 / 运行证据在外部记录，明确尚未完成项、签名状态与交付范围。
- [ ] 得到与当前候选和证据绑定的明确交付 / 发布批准后，由获准发布流程执行；普通开发或 artifact 构建成功不是上传授权。
